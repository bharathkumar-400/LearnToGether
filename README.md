## ✨ 1. Project Introduction

**LearnToGether** is a student-focused social learning platform designed to bring **learning, collaboration, communication, and knowledge sharing** into one place.

### 🎓 Students can

- 👤 Create personal profiles
- 📝 Share learning posts and notes
- 👥 Follow other students
- 🏠 Create and join study rooms
- 🔒 Create public or private classes
- 🎥 Attend online classes
- 💬 Chat with other learners
- 📚 Enroll in courses
- 🧠 Take quizzes and assignments
- 💻 Practice coding problems
- 📊 Track learning progress
- 🏆 Earn points, badges, and achievements
- 🥇 Participate in leaderboards
- 👨‍🏫 Become mentors
- 🤖 Use future AI-powered learning features

---

## 🎯 Project Vision

Our goal is to build **LearnToGether** as a real-world learning ecosystem where students can:

> **Learn → Share → Collaborate → Teach → Grow**

The platform combines ideas from:

| Platform Type | LearnToGether Feature |
|---|---|
| 📱 Social Media | Profiles, Posts, Followers |
| 🎓 Online Learning | Courses, Lessons, Quizzes |
| 💬 Community Platforms | Rooms, Chat, Discussions |
| 💻 Coding Platforms | Coding Problems & Submissions |
| 🤖 AI Platforms | Recommendations & AI Assistant |
